About Me

I'm Gökhan Arda Borulu, a 17-year-old Grade 11 student with a deep passion for technology, Linux systems, and software development.

While still in high school, I built Twilight OS — a complete Arch Linux-based operating system with KDE Plasma 6, universal GPU support, and 50 curated applications. This project taught me everything from shell scripting to CI/CD pipelines with GitHub Actions.

I'm actively learning Python from basics to advanced topics like OOP, GUI development, web scraping, and database management. My goal is to study Computer Science or Software Engineering at the University of Waterloo 🇨🇦 and contribute to the open-source community.
